# Agent Rules

## Clarification Before Action

**IMPORTANT**: If there is any doubt or ambiguity about what the user means, ASK for clarification BEFORE taking any action. Do not make assumptions and proceed - always ask first.

Examples of when to ask:
- Unclear which repository/branch to target
- Ambiguous terminology (e.g., "main branch" could mean different things)
- Multiple possible interpretations of a request
- Any situation where proceeding without clarification could lead to unintended consequences
